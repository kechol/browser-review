# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][cc21] in full.

The canonical text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. We adopt it
by reference rather than vendoring a copy, so that this file cannot drift out of
sync with the upstream wording.

In short: we expect everyone taking part in this project — in issues, pull
requests, discussions, and any other project space — to be respectful, to accept
constructive feedback gracefully, and to focus on what is best for the community.
Harassment, personal attacks, and publishing others' private information are not
tolerated.

## Reporting

To report behavior that violates this Code of Conduct, use GitHub's **Report a
vulnerability** form on the repository's Security tab — it delivers a private
message to the maintainers — or, if the matter is not sensitive, open an issue.

All reports are reviewed and investigated promptly and fairly. Maintainers are
obligated to respect the privacy and security of the reporter.

## Enforcement

Maintainers will follow the Contributor Covenant's Enforcement Guidelines
(correction, warning, temporary ban, permanent ban) when determining the
consequences of a violation.

[cc21]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
